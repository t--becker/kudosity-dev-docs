> 🚧 Kudosity's RCS API is Currently in Beta.

We are rapidly building out our RCS API-First Beta and would love for you to get on board. If you're interested in joining our RCS Beta program or you have any questions about it, please reach out to us at: <https://help.kudosity.com/s/submit-ticket>

## Eligibility

- You're building with APIs — no UI needed (yet)
- You're looking to deliver rich, verified business messages
- You're cool with a bit of rough edge while we finalize things

## 🌍Regional Availability

RCS is still rolling out globally.  
Google’s support varies by country, so let us know where you plan to send — we’ll help confirm what’s supported.

## 🧪 API + Docs: Work in Progress

Our API and docs are evolving fast.  
We don’t anticipate major breaking changes, but some pieces may still be in flux. If something doesn’t behave as expected, tell us — your feedback helps us improve.
