title: Cancel Touchpoint
excerpt: >-
  Deactivates an existing touchpoint which changes its status from `active` to
  `cancelled`.


  Prevents additional messages being sent to existing contacts, and prevents new
  contacts from being added to the touchpoint.


  Once a touchpoint is cancelled it cannot be reactivated.
